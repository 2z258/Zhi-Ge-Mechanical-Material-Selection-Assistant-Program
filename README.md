# 智哥选型 2.0

机械材料智能选型辅助系统。根据零件类型、载荷、工作温度、性能要求、制造方式和硬性条件，从本地材料数据库中筛选并推荐候选材料，并给出匹配度、数据完整度和推荐理由。

> 本软件用于材料初步筛选与方案比较，不能替代正式工程设计、强度计算、疲劳寿命分析或标准审查。

---

## 功能特性

- 按零件类型、工作温度、载荷类型、制造方式和硬性条件筛选
- 支持强度、硬度、刚度、疲劳、韧性、耐磨、耐腐蚀、轻量化、高温、导热等 28 项性能指标
- 内置工程权重：不同零件类型自动侧重不同指标，可在界面中叠加性能要求
- 输出 TOP 3 推荐，显示匹配度、数据完整度、可信度和推荐理由
- 材料详情、横向对比、数据库浏览
- 轴扭转 / 螺栓拉伸 / 梁弯曲 三种强度校核
- 导出 HTML 报告（可浏览器打印为 PDF）和 CSV（可导入 Excel）
- 桌面界面（Tkinter）与本地 Web 界面两种入口
- 支持 DOCX / XLS 材料数据导入，以及联网补全脚本

## 环境要求

- Windows 10 及以上
- Python 3.10 及以上（推荐 3.11+）
- 桌面界面需要 Python 自带 Tcl/Tk
- 仅使用 Python 标准库；XLS 导入额外需要已安装 Excel 与 `pywin32`

## 快速开始

```powershell
# 启动桌面界面
python run.py

# 启动本地 Web 界面
python run.py --web

# 指定 Web 端口
python run.py --web --port 9000
```

Web 界面默认地址：<http://127.0.0.1:8765>

## 使用说明

### 材料选型

1. 选择零件样式和工作温度档位（也可自定义温度）
2. 勾选载荷类型、制造方式、硬性条件
3. 在“性能要求”中选择档位：不考虑 / 较低 / 一般 / 较高 / 很高
4. 点击“开始推荐”，双击结果行查看详情

### 强度校核

在推荐结果基础上，选择校核类型并输入载荷、尺寸和安全系数，点击“计算校核”。

| 类型 | 公式 | 说明 |
| --- | --- | --- |
| 轴扭转 | τ = 16T/(πd³)·K | K 为键槽应力集中系数 |
| 螺栓拉伸 | σ = F/A，A = π/4·(0.75d)² | 未考虑预紧力与弯曲 |
| 梁弯曲 | σ = M/W，M = F·L/4 | 简支梁跨中集中力 |

许用应力优先取屈服强度 / 安全系数；缺少屈服强度时按抗拉强度 / 2.5 估算。

### 导出

- **HTML**：完整选型报告，可在浏览器中打印为 PDF
- **CSV**：推荐结果明细，可用 Excel 打开

## 推荐逻辑

```text
用户需求
  → 合并零件类型 / 载荷 / 自定义权重
  → 硬性筛选（温度、焊接、腐蚀、耐磨、轻量化等）
  → 读取材料参数（已采纳的参数级来源优先）
  → 指标归一化（0~100）
  → 加权综合评分
  → 按分数、完整度排序，取 TOP 3
```

重要规则：

- 缺失数据不会当作 0 分或高分，而是计入“缺失指标”，降低数据完整度
- 匹配度与数据完整度分开显示，避免“数据少但分数高”的误判
- 已知明确不满足硬性条件的材料会被淘汰，并给出原因
- 文字描述只作为参考，不直接参与数值评分

权重规则位于 `rules/weights.json`：

- `base`：所有材料的默认指标权重
- `part_types`：按零件类型覆盖/加强的权重
- `loads`：按载荷类型叠加的权重

## 数据库

唯一运行数据库：`data/materials.db`

主要表：

| 表 | 用途 |
| --- | --- |
| `materials` | 材料主体信息与性能参数 |
| `parameter_sources` | 参数级来源与核验状态（`status='accepted'` 时优先采用） |
| `external_properties` | 外部数据暂存 |
| `material_update_log` | 材料更新日志 |
| `material_update_runs` | 更新批次记录 |

主要字段：

- 力学：抗拉强度、屈服强度、弹性模量、硬度、疲劳强度、延伸率
- 物理：密度、最高工作温度、热导率、热膨胀系数、导电率
- 工艺与文本：加工性、焊接性、热处理、典型用途、原始文本、数据来源

当前库内约 472 条材料，其中 150 个常用牌号已按 GB/T 699/700/3077、ASM、MatWeb 及工程塑料手册补全典型性能值。

修改数据库前请先备份到 `data/backups/`。

## 数据导入

### DOCX

```powershell
python run.py --import-doc "C:\路径\材料文档.docx"
```

纯标准库解析，仅提取能够可靠识别的字段；无法确认的参数保持缺失，不会编造。

### XLS

```powershell
python run.py --import-xls "C:\路径\材料属性表.xls"
```

需要系统已安装 Excel。自动完成单位换算：

- `N/m² → MPa`
- `N/m² → GPa`（弹性模量）
- `kg/m³ → g/cm³`
- `/K → µm/(m·K)`

### 联网补全

```powershell
# 预览将要写入的数据（不修改数据库）
python data/enrich_from_web.py

# 写库（自动备份）
python data/enrich_from_web.py --apply
```

脚本内置权威来源的典型值，并会修复历史数据中的列错位与重复占位值。补入值为标准下限或典型值，关键设计仍应以材质书为准。

## 常见问题

**点击推荐后没有结果？**
检查温度档位和硬性条件是否互相冲突，例如要求耐高温却选了最高温度很低的塑料。

**为什么推荐分数不高？**
分数只统计有数据的指标。缺失指标越多，数据完整度越低，可得分上限也越低。

**为什么有些材料显示“暂无数据”？**
材料库未收录该字段，系统不会臆造数值。

**桌面窗口打不开或报 Tcl/Tk 错误？**
请使用带 Tk 支持的 Python 安装包，或改用 Web 界面 `python run.py --web`。

**XLS 导入失败？**
确认已安装 Excel 与 `pywin32`，且文件未被占用。

## 工程声明

本软件是材料选型辅助工具，不是最终工程设计结论。涉及承载能力、疲劳寿命、稳定性、耐温、耐腐蚀、焊接质量和安全系数的设计，必须结合具体结构、载荷计算、尺寸、制造状态、试验结果和相关标准进一步确认。
